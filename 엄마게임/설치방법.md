# 엄마게임 — 설치 방법

핸드폰 바탕화면에 진짜 앱처럼 깔아드리려면 **인터넷에 한 번 올려두는 과정**이 필요해요
(파일을 폰으로 직접 옮기는 것만으로는 "바탕화면에 추가"가 완전히 동작하지 않아요).
딱 5분이면 됩니다.

## 1단계. 무료 호스팅에 폴더 올리기 (Netlify 추천, 가입 필요 없음)

1. 컴퓨터에서 **https://app.netlify.com/drop** 접속
2. 이 zip 파일 안의 `엄마게임` **폴더**를 통째로 그 화면에 드래그해서 놓기
   (zip 파일 자체가 아니라, 압축을 푼 폴더를 올려야 해요)
3. 몇 초 뒤 `https://이상한이름.netlify.app` 같은 주소가 생겨요. 이 주소를 복사해두세요.

> 다른 방법: GitHub Pages, Vercel, 카페24 등 아무 정적 호스팅에 올려도 됩니다.
> `index.html`, `manifest.json`, `sw.js`, `icons` 폴더가 같은 위치에 있어야 해요.

## 2단계. 어머님 폰에서 그 주소 열기

생성된 주소를 문자나 카카오톡으로 보내드리고, 눌러서 열게 도와주세요.

### 안드로이드(삼성, 갤럭시 등) — 크롬(Chrome) 브라우저
1. 주소를 열면 화면 아래에 **"홈 화면에 추가"** 알림이 뜰 수 있어요 → 누르면 끝!
2. 안 뜨면: 오른쪽 위 **점 세 개(⋮)** → **"홈 화면에 추가"** → **추가**

### 아이폰 — 사파리(Safari) 브라우저 (꼭 사파리로 열어야 해요)
1. 화면 아래 **공유 버튼**(네모에 위쪽 화살표 ⬆️) 누르기
2. 아래로 내려서 **"홈 화면에 추가"** 누르기
3. **추가** 누르면 끝!

이제 홈 화면에 예쁜 꽃 아이콘이 생기고, 그걸 누르면 다른 앱처럼 바로 열려요.
인터넷이 잠깐 안 되어도 이미 열어본 게임은 계속 할 수 있어요.

## 게임 소개
앱을 열면 두 가지 게임을 **각각 따로** 골라서 할 수 있어요.

1. **카드 뒤집기** — 카드를 눌러 뒤집어서 같은 그림 두 장을 찾아요. (기억력 게임)
2. **그림 짝 찾기** — 그림이 처음부터 다 보여요. 같은 그림 두 개를 눌러서 짝을 찾으면 돼요. (관찰력 게임)

두 게임은 서로 완전히 독립적이에요. 오늘은 카드 뒤집기만, 다음엔 그림 짝 찾기만 하셔도 되고,
어느 게임이든 원하실 때 골라서 하시면 됩니다. **단계 진행도 게임별로 따로 저장**돼서
카드 뒤집기 5단계, 그림 짝 찾기 2단계처럼 서로 다르게 진행하셔도 문제없어요.

- 각 게임마다 총 **15단계**가 있고, 단계가 올라갈수록 카드 수가 점점 늘어나요.
  (1단계 12장 → 15단계 48장. 처음부터 살짝 도전이 되도록 만들었어요.)
- 꽃 그림이 매 단계마다 꼭 들어가고, 과일·동물·자연처럼 친근한 그림만 사용했어요.
- 글씨와 버튼을 크게 만들어서 손가락으로 누르기 편하게 했어요.
- 어디까지 깼는지 자동으로 저장되어서, 다음에 열면 이어서 할 수 있어요.
